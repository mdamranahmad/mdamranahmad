## 🧭 About Me

I'm a **Backend Developer & Full Stack Web Developer** who enjoys the part of the stack most people avoid — designing the data model, wiring the API, and making sure the whole system holds up when real users show up. I work across the stack when a project needs it, but my core strength is building the **backend logic, database architecture, and API layer** that everything else depends on.

I like clear requirements, clean commits, and shipping things that actually work in production — not just on `localhost`.

🔭 **Currently exploring:** Next.js and the App Router — extending my backend-first foundation into full-stack React so I can own a project end-to-end, frontend included.
